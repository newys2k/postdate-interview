# Post-date debrief

```bash
npm install
npm run dev
```

Open the printed URL (on your iPhone, use the Network address on the same Wi-Fi).

- **Questions, copy, verdicts:** `src/config/questions.js`
- **Colors and fonts:** `tailwind.config.js`
- **shadcn/ui components:** `src/components/ui`; **Magic UI:** `src/components/magicui`
- Answers and progress persist in `localStorage` (key set in `meta.storageKey`).
